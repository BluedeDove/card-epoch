**结论：动机增强未观测到。** RationalAgent 的估值表把矿速率写死成 1/3s/矿（看不到温度），
热矿在它的决策里与冷矿同价——升温不改变行为是这件事实的直接后果。卖点"热矿成为争夺焦点"要成立，
需要代理（与真人 UI 提示）看得见矿温；这超出本刀范围，如实登记给 A2 的 RationalAgent v2。
