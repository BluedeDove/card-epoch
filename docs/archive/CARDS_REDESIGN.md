# 卡牌重设计 · 2026-10-17 第三/四批

> 本文只记**这一轮实际改了什么、凭什么说改对了**。数值的权威口径仍在 [GAMEPLAY.md](GAMEPLAY.md)，
> 视觉的原子/配方口径在 [FX_ATOMS.md](FX_ATOMS.md)。玩家可见文案照旧只出现在 `js/cards.js`（卡面文字，纯数据）。

## 0. 用户点名的五件事

1. 墙"只生成地面上那一格，挡不住敌人"——要一键生成**真的挡得住人**的大墙 / 地堡。
2. 桥"点到哪生成哪"，要**朝一个方向扔出去、沿抛物线铺过去**（空中也要能铺，不该考验瞄准）。
3. 缺"毁天灭地"的大招爆炸系，且**尺寸要有梯度**（不是全部都巨大）。
4. 要**核弹级**的、"整幅地图一起玩没了"的终末法术。
5. 召唤物都在地面走——要**会飞、粒子打满**的；追踪弹"直直走过去没意思"，要**细小粒子 + 空中画弧线**的烟花类。
6. （追加）超阶魔法：**几十座大型法阵 → 长动画 → 毁天灭地**。

## 1. 结算层新增的三条能力（都在权威层，不在 UI）

| 能力 | 位置 | 说明 |
|---|---|---|
| 逐卡格子预算 `ef.maxCells` | `rules.js` `R.effectCap` / `R.cardCellCap` | 默认仍 9 格；大建造卡在数据里声明 12~96，硬顶 `CARD_CELL_CEIL = 96`。**价格仍是素材按格扣**（`R.priceTerrain` 唯一真源），付不起就部分成交 |
| 魔法构筑 `ef.conjure` | `rules.js` `R.priceTerrain` | 该效果**不计素材**，价格挪到魔力 + 冷却上。这是"一键地堡"唯一走得通的路：按格扣的话 5×5×3 的地堡要 85 素材，整局攒不出来 |
| 多法阵 / 仪式 | `rules.js` `case 'sigil'` + `cards.js` `sg(id, delay, ttl, dx, dz)` | 一张卡可以铺十几座阵，各自带 preset 与相对偏移；`battle.js` 只按 preset 结算 |

新增地形模式：`wall`（按瞄准面站到地面上、先砌满高度）、`bridge`（从脚下起铺、朝相机方向、桥钉抛物线铺板）、
`cage`（支持 `radius`，砌周长）、`bunker`（四壁 + 屋顶 + 门洞）、`crater` / `moat`（碗形坑 / 环壕）。

## 2. 建造系：墙与桥

- **墙站不住的真因**：`wall` 模式把墙砌在"瞄准到的那一格方块"上（通常就是草地那一格），
  于是先把地面换成建材、只剩上面 1 格——这正是用户看到的"地面往上一格"。
  现在与 `fill` 同一口径：按**瞄准面**偏移一格落位（`rules.js` 的 `fy0/fx0b/fz0b`）。
- **部分成交的形状**：铺法顺序改成"先砌满一列高度、再往侧面长"。素材只够 5 格时拿到的是 4 格高的墙，
  而不是一道高 1 的长坎。这条被 `tools/cards_probe.cjs` 的"墙高 ≥2 / 4 格高的一列全立起来"守着。
- 新增 `bastion`（8 长 × 4 高，最多 32 格，素材计价）、`fortress` 改成 3×3 魔法构筑地堡、
  `bunker`（5×5 + 屋顶 + 门洞，96 格，conjure）、`raze`（外圈挖成壕沟 + 中间立黑曜石地堡 = "拆+建"组合）。
- 桥：`bridgeArc` 语义换成"起铺点在自己脚下、方向取相机朝向"，**桥钉是一发抛射物**（`spawnBridgeQuill`），
  沿抛物线飞过去、沿途把已经报过价的格子落地（`paintBridge`），到点补齐。空中起跳也能铺。

## 3. 爆炸系：尺寸梯度

| 卡 | 半径 | 伤害 | 材质/地形 | 冷却 |
|---|---|---|---|---|
| `firework` 星雨 | 9 发 5 伤（追踪） | — | — | 4s |
| `meteor_rain` 陨星雨 | 阵 3.5 / 每颗 2.6 | 22/颗 × ~9 | 点燃 | 24s |
| `supernova` 超新星 | 6.2 | 48 | 点燃 + 震屏 | 22s |
| `void_collapse` 奇点 | 5.0 | 34 + 吸引 | 减速 | 20s |
| `earthsplit` 裂地 | 碗 3 格深 | 20 + 定身 | 坑 30 格 | 18s |
| `terminus` 终末 | **34**（整图） | **62（敌我不分）** | 大碗坑 13 格半径 | 75s |
| `grand_ritual` 超阶·万象归寂 | **26** | 46 | 碗坑 11 | 90s |

- 陨星是**真弹**（走玩家那条抛射物通道：子步推进 / 近失圈 / 命中起爆 / 物质层催化），
  所以"躲到墙后面挡陨石"是真的可行。
- 终末与超阶都走 `battle.js` 的 `detonateNuke`：半径内**所有**实体（含施放者）吃伤害，
  地面按碗形挖掉（封顶 900 次 `world.set`），震屏 + `fxEv('nuke')`。

## 4. 飞行召唤

`battle.js` `stepFlyer`：不吃重力、不做体素碰撞（只守"别钻进方块"与竞技场边界），
三种行为 `ranged`（绕圈隔空开火，弹道复用玩家那套抛射物）、`suicide`（撞上去自爆）、`flank`（压在头上近战）。
光环按 `aiKind` 查 `V.SUMMON_FX`（`aura_void_wisp` / `aura_hawk` / `aura_bee`），挂**身体中心**而不是脚下。

## 5. 追踪与光弧（"不要直直走过去"）

- `battle.js` `steerProjectile`：每秒 `turn` 弧度的转向上限 + 正弦横摆 `weave`。
  转向有上限，所以画出来是**弧线**而不是折线；`acquireTarget` 每次失去目标就重新找最近的敌人。
- `vfx-render.js` 的**光弧**：每个抛射物留 20 点轨迹史（存在渲染层自己的表里，实体上一个字段都不写），
  每帧重画成一条渐隐折线。转得越急、弧线越明显——这是"空中画弧线"的实现，不是贴图。
- 顺手修掉一个真 bug：抛射物字面量里 `kind` 被写了两次（`'projectile'` 被伤害类型覆盖），
  于是 `VFX.defaultFor` 的 `'projectile'` 分支从来没命中过，**抛射物拖尾一条都没画出来**
  （node 探针实测 `frameOf(pr,'trail').layers = 0`）。现在拆成 `entKind`（实体种类）+ `kind`（伤害类型），
  插值上限也按 `entKind` 取（`INTERP_MAX.projectile = 3.4` 这才真正生效）。

## 6. 特效层的扩展（先扩类，再组合）

- **原子类 8 → 11**：新增 `dome`（线框半球罩：体积感）、`helix`（螺旋带：运动感）、`shards`（确定性散点：炸开感）；
  平面类的 `tilt` 上限从 ±1.2 放到 ±π/2（**竖起来的冲击环**）。
- **配方 39 → 58**：`cataclysm_seal` / `ev_meteor_impact` / `ev_supernova` / `ev_quake` /
  `ev_raise_wall` / `ev_bridge` / `aura_void_wisp` / `aura_hawk` / `aura_bee` / `meteor_trail` /
  `sigil_cataclysm` / `sigil_terminus` / `sigil_ritual_a|b|c|core` / `ev_nuke` / `ev_firework` / `spirit_trail`。
- 新绑定表：`PROJECTILE_FX_CARD`（按卡 id 定拖尾/命中）、`SUMMON_FX`（按 aiKind 定光环）。
- 预算纪律照旧：单条配方 ≤14 层、单环 ≤96 点、槽位 ≤300。刻意为之的两处"降档"：
  十几座仪式阵各自**只留 3 层、透明度 0.72**（叠起来才不会烧成一片白）；核爆的 `ev_nuke` 只到 0.85 半径的罩子
  （第一版 lon 24 的罩子在 14 格半径下变成罩住半个屏幕的线笼子——截图自查抓到的）。

## 8. 已知限制（如实）

- **素材经济与大建造**：除 `conjure` 那几张，大墙仍按格扣素材，前期只能砌出一小段——这是"素材按格扣"的必然结果，
  不是 bug。要不要整体放宽，是玩法线的决定（定案 §2.2）。
- **核弹/超阶是"爽"优先**：`terminus` 敌我不分、`grand_ritual` 90 秒冷却；数值没进 play_probe 的 T 组枚举
  （现在的 AI 不一定会打这两张），所以"是否失衡"目前没有量化信号。
- **视觉只在 SwiftShader(≈11–15 FPS) 下看过**：真机观感（尤其仪式阵的层次感）需要用户在 160FPS 的机器上判断。
- 卡面美术：新卡沿用现有 art 画笔（无专属像素图）。
- 屏上那些**纯白方块**不是本线的：`js/atmos.js`（大气线，未提交）的降水粒子用的是无贴图 Points，截图里很显眼。
## 9. 第二轮（用户追加）：威力对齐特效 / 配色不再保守 / 吸附一切

**9.1 陨星雨升级（"特效炫酷的法术，威力也该同步很大"）**
- 阵半径 3.5 → **6.5 格**、持续 4.5 → 5.5 秒、每 0.5 → 0.45 秒一颗、单颗 22 → **30 伤害 / 3.4 格**；
  价格 6 → 7 费、冷却 24 → 28 秒。
- **每颗流星都砸坑**：`battle.js` 新增共用挖坑器 `digCrater(x,y,z,r,depth,budget)`，
  陨星落地（命中实体或砸到方块两条路径都算）挖 `2.2 格 / 3 深` 的碗；核爆也改用它（900 格预算）。
  探针断言：阵区地表被砸空 ≥12 格。

**9.2 黑洞（用户点名的"吸附一切"）**
- 新卡 `black_hole` 奇点·吞噬：阵半径 5、持续 7 秒、每 0.4 秒磨 6 点，并且**每 tick 位置推移**把我方以外的人拽向阵心。
- 为什么不用速度增量：玩家/随从的 `applyInput` 每 tick 都在把速度往输入方向拉（加速度 44），
  外来的速度 8 个 tick 就衰减光——实测 2 秒只挪 0.34 格（读感是"黑洞没用"）。
  改成位置推移（1.4 格/秒，仍会被 `collideAABB` 撞墙挡住），实测 2 秒拽近 >0.8 格。
- 视觉：紫 / 洋红 / 电光青三层对撞 + 纯白奇点（`sigil_black_hole`）。

**9.3 配色：从"元素色"到"光谱 + 撞色"**
- `cards.js` 的 `G.ELEMENTS` 每个元素新增 `spectrum: [4 个纯色]`（color/accent 原地不动，UI 与老配方不受影响）。
  虚空 = 白 / 紫 / 洋红 / 电光青；焰 = 白黄 / 金 / 橙 / 猩红；霜 = 白 / 冰 / 青 / 电蓝；岩 = 米 / 土 / 褐 / 紫；林 = 黄绿 / 绿 / 青绿 / 电光青。
- 卡面（`js/ui/art.js`）优先用卡自己的 `tint`（两张撞色），否则用 `spectrum[1]/[2]`——比原来的 color/accent 更饱和。
  10 张招牌卡带 tint（超阶 / 终末 / 陨星雨 / 超新星 / 灵光 / 星雨 / 雷隼 / 浮灵 / 翻天覆地 / 奇点）。
- 大配方逐层显式给 `color/color2`，用的是 **RGB 纯色**（#ff00a8 / #a020ff / #00ffff / #ff0050 / #ffe600），
  相邻两层用互补色对撞——additive 叠加时两色互相"咬"，读感是色偏/撕裂，而不是一圈温吞淡紫。
- 说明：加法混合在亮草地上**必然**往白推（AGENTS 里记过），所以纯色层 + 暗底描边是这套渲染的极限；
  要更极端的色偏需要改成 screen/overlay 混合，那是渲染层的事，不在这一轮。

## 11. 第三轮（用户追加）：召唤分类 / 多段节奏 / 全卡自动配方

**11.1 两类召唤（"要区分出自动跟踪和指向性两类"）**
- 数据：`sp(kind, count, { mode: 'track' | 'direct', leash })`。
  `track` = 自动索敌（浮灵 / 爆蜂 / 烬羽 / 岩魔）；`direct` = 指向性（雷隼 / 树精）。
- 权威实现：`spawnSummon(owner, ef, card, aim)` 在 `mode==='direct'` 时**直接生成在瞄准点**并记 `home`；
  `stepSummons` 里目标跑出 `leash` 就放弃、回岗（`state='guard'`）。探针实测：雷隼离瞄准点 <4 格、敌人跑到 20 格外仍在绳长内。
- 剪影：`makeSummonMesh` 逐个 aiKind 不同（岩魔/树精/雷隼/爆蜂/浮灵/烬羽=火鸟），不再"一个球换颜色"。
- 轨迹：`vfx-render` 把**召唤物也接进光弧系统**（飞行或在地面奔跑的都留一条渐隐光带），颜色取它自己的 `boltEl`。

**11.2 多段节奏（"别总是大前摇、嘣一下就完了"）**
- 计算层新增动画通道 `beatAt / beatW / beatK`：一层可以在指定秒数弹一次（指数衰减），
  自动配方里 1 费单拍、3–4 费两拍、5 费以上三拍——**所有卡的起手特效自带节奏**。
- 权威层新增 `preset.beats = [{at, dmg, radius, knock, ff, crater, status}]`：每拍都真结算，
  `fxEv('beat')` 让画面按序号升档（小爆 → 陨石冲击 → 核爆罩）。
- 终末改成三拍：3.0s 冲击波（14/16 格）→ 3.45s 第二拍（24/24 格）→ 4.0s 主爆（62/34 格 + 塌坑，敌我不分）。
  探针按"三段跌血"断言（400 → 397 → … → 见输出），不再是"一口气砸完"。
- 修真 bug：`bt.done` 曾写在 **preset 上**（全局共享），第一座阵打过之后所有阵都哑掉；改成记在 `s.beatDone`。

**11.3 全卡自动配方（"迁移要适配到所有卡牌"）**
- `VFX.autoRecipe(card)`：按（元素光谱 × 卡种 × 费用档 × 卡 id 的确定性哈希）**组合**出配方——
  外圈刻度环、内层星形、体积（柱/旋涡/螺旋/罩）、4 费以上挂 `sat` 法针圈、6 费以上加球壳、符号带收尾，外加 1–3 段节拍。
- 查表顺序：手写配方（`CARD_BY_ID_FX`）→ **自动配方** → 元素 → 卡种兜底。
  实测 **73/73 张卡都有配方、都求得出层**，recipe 总数 59 → 自动配方按需注册。
