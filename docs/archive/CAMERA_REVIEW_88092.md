## 3. 我怀疑的方向（**待验证，不是结论**）

按 AGENTS 冻结的口径，两边判"身体是否糊准星"用的是**不同量**：
- `js/main.js` 的 `heroGroups` 判"该不该藏"用前方角点的**相机空间深度**（阈值约 1.45）；
- `tools/cam_audit.js` 判"不该画却画了"用**部件投影是否进准星区**。

64 图的 88092 出现了一批"深度 2.80 格 + 投影间隙 2.1% 屏宽"的姿态：深度侧判"不挡"（2.80 > 1.45），
投影侧判"挡住了还画着"（2.1% 小于准星半宽）→ C2/C3 成批红。这与 AGENTS 里那条老教训同型
（"邻近判定必须与审计同口径，用相机空间深度而非欧氏距离，否则一个漏判一个过判"），
只是这次是**场地从 96 换到 64 把这批姿态推到了两条口径的分歧带里**。
