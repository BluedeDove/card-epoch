> 谁能拦：`node tools/ui_shot.cjs --gate`（字号 / 对比度 / 安全边距 / 令牌外颜色 / 圆角 / 模糊阴影，

## 0. 一句话定位

**深色石板 + 黄铜描边的"法师手账"**：世界是亮的（草地/天空），HUD 就必须是压得最低的深色块；
元素色只当**印章**用（费用牌、底部一条元素带、图章底色），**不再给整格描边**——
以前 56 张卡的彩虹描边就是"丑"的第一来源。

## 1. 六条硬口径（从检索来，落到本项目）

1. **中央让位**：常驻层只占左上角一块 + 底部一条带 + 右上日志。正中央只留准星与命中格信息，
   任何常驻面板不得进中央 40%（研究里八款产品没有一把常驻面板放在中央）。
2. **三档信息层**：常驻（血/蓝/素材/手牌）永远在；情境（悬停提示、准星那行、详情栏）跟着指针；
   瞬时（toast / 日志新行）出现后自动退场。瞬时层不许抢常驻层的位。
3. **对比达标**：正文中文对底 ≥4.5:1，大号数字（≥22px）≥3:1；文字一律带 1px 硬暗描边，
   保证压在任何体素背景（亮天空 / 暗岩层）上都读得出。机检用**三个世界底色**（亮天空、亮草皮、暗岩层）各量一遍。
4. **硬边**：全部直角、2px 外描边 + 1px 内亮线，阴影只用 0 模糊的硬偏移；
   不用 blur、不用 border-radius（老版费用牌是 50% 圆，与像素风打架）。
5. **可点 / 不可点必须两件事一起说**：不可出的卡 = 费用牌转红 + 压暗**但字仍读得清**，
   不清一色灰、不隐藏（研究里 StS / Balatro 都是这么处理费用不足的）。
6. **选中态四件套**：抬升 + 亮边 + 提层 + 内衬加亮，缺任一都会被玩家误判成"没选上"
   （旧版元素色把 gold 选中框盖掉了，就是这个坑）。

## 2. 设计令牌（与 src/ui/theme.css 的 :root 一一对应）

### 2.1 颜色

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--ink-0` | #06050e | 遮罩底、外描边（不是纯黑，纯黑压在深色世界上"死"） |
| `--ink-1` | #100d1f | 面板底（石板） |
| `--ink-2` | #17132e | 面板内层 / 输入区底 |
| `--ink-3` | #221b40 | 控件面（按钮、页签、格子） |
| `--ink-4` | #2d2455 | 控件 hover |
| `--line-1` | #3d3470 | 常规描边 |
| `--line-2` | #6b5cc0 | hover / 焦点描边（比旧 #5a4c93 提一档，才够 3:1） |
| `--brass` | #ffd86b | 强调：标题、选中、主按钮描边 |
| `--brass-dim` | #9a7f3a | 分隔线、次级标 |
| `--txt-1` | #f2eeff | 正文（对 ink-1 ≈ 14:1） |
| `--txt-2` | #b6aedd | 次级说明（≈ 8:1） |
| `--txt-3` | #8b83b8 | 仅用于 ≥12px 的元信息（tick/FPS 这类），不承载必须读到的信息 |
| `--hp / --sh / --mn / --mat` | #ff5f7a / #7fd7ff / #8b7bff / #8ce08a | 生命 / 护盾 / 魔力 / 素材 |
| `--ok / --bad` | #6ee7a0 / #ff6b6b | 允许 / 拒绝 |
| 元素色 | 用 `src/cards.js` 的 `G.ELEMENTS[*].color`（经 `--ui-tone` 传进 CSS） | 只在费用牌、元素带、图章底色三处 |

**规则**：颜色只能来自这张表（含元素色）。ui_shot 的体检会把"算出来不在这张表里的颜色"打进行号清单。

### 2.2 字号（只准这 5 档）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-1` | 12px | 元信息：tick / FPS / id / 计数（拉丁与数字为主） |
| `--fs-2` | 14px | 密集标签：格子名、chips、详情小标题 |
| `--fs-3` | 16px | 正文：日志、提示、卡面说明、表单 |
| `--fs-4` | 22px | 要扫一眼的数字：血 / 费用 / 计时 |
| `--fs-5` | 32px | 展示：菜单标题、结算标题 |

检索给的口径是"中文正文 ≥18px"。这里正文取 16px 是权衡后的值：背包一屏要放 56 张卡与四段说明，
18px 会把卡片压到看不清图章；代价是**必须**在 dpr=1.5 与 1080p 各截一张图核对（`ui_shot --dpr 1.5`）。
凡是"扫一眼就要读到"的量（血、费用、剩余时间）走 `--fs-4` 以上，这一条不打折。

### 2.3 其它

- **间距**：4px 网格 —— `--s1:4 / --s2:8 / --s3:12 / --s4:16 / --s5:24 / --s6:32`。任何 padding/gap 只用这 6 个值。
- **边框**：`--edge:2px` 一档到底；面板再加 `inset 0 0 0 1px` 内亮线。**不允许出现 3px / 4px 边框**（旧版三种粗细混用）。
- **圆角**：`--radius:0`，全局不用。
- **阴影**：只用 0 模糊的硬偏移（`--drop:0 4px 0 rgba(0,0,0,.45)`）。模糊只允许出现在**选中格的一层辉光**（`--glow-sel`）与准星命中的那一点光晕上。
- **动效**：`--t1:90ms / --t2:140ms / --t3:220ms`，缓动 `cubic-bezier(.2,.8,.2,1)`；`prefers-reduced-motion` 时位移类全部关掉（颜色类保留）。
- **安全边距**：HUD 贴边元素与屏幕外沿 ≥3.5%（`--edge-pad`），机检量 rect。
- **字族**：中文走系统无衬线（`Microsoft YaHei UI / Noto Sans CJK SC / PingFang SC`），
  数字与 id 走等宽（`Consolas / DejaVu Sans Mono`）并开 `font-variant-numeric: tabular-nums`——
  旧版全站 `DotGothic16, Courier New, monospace`：中文在 Windows 上被 Courier New 兜底，是"字体很怪"的根因。
  像素位图字体（OFL）等本机有网络通道时按 `vendor/fonts/` + `@font-face` 补，不引用外链。

## 4. 组件口径（src/ui/widgets.js 的货架）

- **`.ui-panel`**：任何面板底都走这个类 —— `--ink-1` + 2px `--line-1` 描边 + `--edge-ring` 内亮线 + `--drop` 硬阴影 + 1px 扫描线纹理。
- **`.ui-head`**：面板头 —— 左侧小标题（`--fs-2`、字距 2px、`--brass`）、右侧插槽（关闭提示 / 计数），底边 2px `--line-1`。
- **`.ui-btn`**：`--ink-3` 面 + 2px 描边 + `--t1` 过渡；hover 抬升 1px 并把描边提到 `--line-2`、文字变 `--brass`；
  `:active) 下沉 1px 且硬阴影归零；`:focus-visible` 给 2px `--ok` 外环（对比 ≥3:1）；`.pri` 是黄铜面 + 深色字（唯一的高饱和块）。
- **`.ui-slot`**：格子；`--ui-tone` 由 widgets 传下来（**自定义属性**，dom.js 的 writeStyle 支持 `--*`），
  边框永远是中性色，元素色只出现在底部元素带与费用牌。
- **`.ui-meter`**：轨道 `--ink-2` + 内凹暗线，填充用 `--bar` 色 + `repeating-linear-gradient` 打出 8px 一格的**分段缺口**（像素表的最便宜做法，不用多余 DOM）。
- **`.ui-kbd`**：键帽 —— `--ink-3` 面 + 上亮下暗的硬 3D（`inset` 阴影）+ 等宽字。
- **`.ui-tip`**：提示由 describeItem 的行组成：第 1 行＝名称（`--fs-3` + `--brass`），第 2 行＝类型行（`--fs-1`），其余＝正文；左侧一条 `--ui-tone` 竖带。

## 5. 加/改一个面板的落地步骤（沿用 AGENTS 的五步，这里只补视觉口径）

1. 结构进 `src/ui/panels.js` 的 spec，**先查这张表有没有对应类**；要新类名就同时在本文件加一行说明。
2. 样式进 `index.html` 的 `.ui-*` 段：只用第 2 节的令牌，**不写字面色值、不写圆角、不写模糊阴影、不写 z-index**。
3. 中文进 `src/hud.js` 的 `H.TEXT`（包括面板头小标题、chips 的标签、键帽提示）。
4. `node tools/ui_check.cjs` + `node tools/creative_check.cjs` + `node tools/layer_check.cjs` + `node tools/ui_shot.cjs --gate --shots /tmp/ui-aFTER`，然后**逐张看图**（绿灯不等于好看）。

## 5.4 类别手持栏（2026-10-17 用户：整场实时性要求强，"想一直挖方块却一不小心甩出技能"）

手持栏是**当前类别**的那几张牌：背包左栏（或 Shift+滚轮）切到"挖掘"，五格里就只会出现挖掘类；
同类打光**宁可空着**也绝不掺别类——"这一格一定能挖"必须是可承诺的事，这条由 `tools/hand_check.cjs` 量。
类别只有五个键（`terrain/spell/sigil/summon/utility`，真源是 `src/cards.js` 每张卡的 `type`）；
中文与顺序在 `H.TEXT.inv.categories`/`classOrder`，视图经 `channel.ask('classOrder')` 取，权威层只认 type。
`p.handClass = null` 是"全类"= 老行为（AI、P2、既有回归都走这条，`hand_check` 有一条"逐字节等价"断言钉住）。
生存模式同样有物品栏与背包（E）；图鉴取卡与调试页仍是创造能力（文案表里标 `creativeOnly`）。

## 5.5 交互契约（好看之外，2026-10-17 用户报"功能全坏"后补）

视觉之外，界面与游戏之间还有四条必须一直接着的线（断掉时**没有任何一条会报错**，玩家只看到"点了没反应"）：

| 线 | 断了会怎样 | 谁拦 |
|---|---|---|
| 选中格数组同一份引用 | 装配层整替 `G.HUD.sel` → 滚轮换卡界面不动 | ui_check「装配层与视图模型握的是同一个数组」 |
| 暂停时也喂 viewmodel | 背包里给卡 → 权威变了画面不动 | ui_check「暂停中给了卡，背包那一排的画面马上跟上」 |
| 悬停按真实 dt 计时 + 主体不被抹掉 | 提示/详情栏永不填 → 卡页四按钮静默 | ui_check「鼠标静止悬停也出提示」「手移向按钮时主体不被抹掉」 |
| 拒绝要演出来（notify 订阅 + toast 单位=毫秒） | 所有"诚实的拒绝"都是沉默 | ui_check「被拒必须演出来」「方块丢到世界…说清楚」 |

再加一条：**权威格的格位不许带 `-1` 发意图**（用 `slotPolicy:'selected'` 或按指针算最近一格）——`creative.give` 会把负数夹成第 0 格，看着就是"拖不动"。

## 6. 谁来拦（2026-10-17 实测）

`node tools/ui_shot.cjs --gate` 在**真页面计算样式**上量八条，任何一条红就退出码 1：
A 字号只准 5 档 · B 对比度（正文 ≥4.5:1、大字 ≥3:1；压在透明层上的按"亮天空 / 亮草皮 / 暗岩层"三种世界底色各量一遍取最坏）·
C 边框四边只准 0/2px（1px 只准单边分隔线）· D 零圆角 · E 零模糊阴影（选中格那层辉光是唯一例外）·
F 颜色必须来自令牌表（`:root` ∪ `G.ELEMENTS` ∪ `BLOCK_DEFS`）· G 常驻层不进中央 40% 且**两两不相交** · H 安全边距。
外加 `--el-*` 与 `G.ELEMENTS[*].color` 的同值核对（元素色只有一个真源，与 `audio_check` 反查音效名同一套路）。

跑法（**两档都要跑**，布局类问题只在 dpr≠1 或窄一档时露头）：`node tools/ui_shot.cjs --gate` 与 `--viewport 1280x720 --dpr 1.5 --states split`。
违规条数与断言条数**以脚本现跑为准**——本文不缓存某一天的红/绿或条数快照（写死了就是下一个会话的假事实）。
它上线当天抓出来的四件事（都不是"样式不好看"而是功能坏了）：分屏 P2 手持栏被 CSS 优先级拽到与 P1 重叠（看不见）、
键位带在 1280 宽压住血条数值、`--ui-cd` 冷却遮罩因 `dom.js` 不支持自定义属性而从未生效、`battle.js`/`rules.js` 把色号抄进了逻辑层。

## 7. 已知没做到的（诚实）

- 位图像素字体（中文）没有：本机 `fc-list` 里没有任何像素字体，且 bash 侧没有出网通道（curl 连不上 raw.githubusercontent.com），
  `无外链` 这条也不允许 CDN。现在靠"系统无衬线 + 等宽数字 + tabular-nums"，视觉上比真像素字软一档；
  等有下载通道时把 OFL 字体放进 `vendor/fonts/` 再 `@font-face`（放 `index.html` 里就是第 2.3 节那个位置）。
- HUD 字号缩放（研究建议的"允许玩家缩放 HUD 文本"）还没做入口；现在只有 5 档令牌。
- 手柄图标提示：本项目没有手柄输入，按研究口径"跟随输入设备"= 只显键盘键帽，不做双套。
- `--txt-3` 这类元信息色在**极亮背景**（雪原 + 关光影）上会掉到 4.5:1 以下；靠 1px 硬暗描边撑着，
  若以后做雪地群系 HUD，要给它单独加底。
